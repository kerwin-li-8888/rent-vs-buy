# 租买资产计算 · Rent vs. Buy

这套房，买还是租？本项目用一个**无需联网的单文件网页计算器**，把"买房"与"租房"两条路径放进同一本账：逐月计入贷款本息、持有费用、租金与剩余现金收益，算出同一持有期末的资产差，并反推两个打平值——

- **按当前月租，期末要卖到多少钱，买房才不吃亏**；
- **按当前卖价，相当于第一年月租多少**。

所有计算在浏览器本地完成：不联网、不装依赖、不上传任何数据。

## 快速开始

1. 下载或克隆本仓库；
2. 用任意现代浏览器打开 [租买资产比较.html](./租买资产比较.html)，双击即可，无需服务器；
3. 填入拟成交价、持有年限、贷款、月租等条件，结果即时重算；
4. 点"复制测算摘要"，可把结果粘贴进自己的房源笔记；也可把仓库部署到任意静态托管（如 GitHub Pages）在线使用。

页面默认值即 [计算方法](./租买资产比较计算方法.md) 第四节的匿名演算示例：买入 200 万元、持有 10 年、组合贷 100 万元（公积金 50 万／2.6%＋商贷 50 万／3%，各 24 年）、第一年月租 5,400 元。打开页面应显示组合贷月供 **4,773.12 元**、打平所需期末卖出价约 **210.48 万元**，与文档手工演算一致——可当作自检基准。

## 计算逻辑速览

- 每笔贷款独立按**等额本息**逐月摊还，支持公积金＋商业贷组合、各自金额利率期限；
- 两条路径从同一期初现金出发，月末分别支付"月供＋物业"（买房）或"房租＋物业"（租房），剩余现金按统一年收益率逐月复利；
- 期末买房资产 ＝ 剩余现金 ＋ 卖价 ×（1－费率）－ 固定税费 － 剩余贷款 ＋ 可移动设备残值；租房资产 ＝ 剩余现金 ＋ 押金返还等；
- 令两边相等，反推打平卖价 `S*` 或打平第一年月租；支持租金逐年上涨、押金、残值等补充现金流。

利息与机会成本**不重复扣除**：每月月供里的利息已付、已还本金转为房屋权益，剩余现金的机会成本已按月复利计入——这是手算最常出错的地方，完整口径与防错说明见 [计算方法文档](./租买资产比较计算方法.md)。

## 结果怎么读

"打平卖价"是一个**条件结果**：在所填的租金、融资、收益率和费用成立时，未来实际成交价需要达到的数额。它不是房子的当前估值，不是未来售价预测，不是全额现金回本价，也不自动成为出价上限。租房与买房的通勤、装修自主性、稳定性与居住品质差异，应在资产结果旁单独判断，不折算成现金。

页面中的零值只表示"尚未计入的假设"，遇到真实房源须按报价逐项核实，不应视为费用必然为零。每次比较建议保留多个拟成交价情景，并对租金、装修投入、卖房税费、资金收益和贷款期限各做一轮敏感性对照（文档第五节给出了示范）。

## 政策核验点（编写时以广州为例）

- 广州现行公积金贷款办法规定，贷款期限一般不超过 30 年，二手房贷款期限与抵押物楼龄合计不超过 50 年，还受土地剩余使用年限及借款人年龄等条件限制。老房不能直接按"30 年组合贷"演算后当成获批结果；实际额度、利率、年限以银行与公积金中心的逐套审批为准。[广州住房公积金个人住房贷款实施办法（2026）](https://www.conghua.gov.cn/zwfw/ztfw/zfgjj/content/post_10849432.html)
- 示例中的公积金 2.6% 采用已公布的五年以上首套住房公积金贷款利率；商贷 3%、现金收益 2%、买入费用 5 万元和卖出费率 1% 均是演算假设，不能代替当次报价。[广州市人民政府关于公积金利率的说明](https://www.gz.gov.cn/zt/shb/content/post_10646354.html)
- 目前个人出售购买满 2 年的住房免征增值税；自用满 5 年且为家庭唯一生活用房的所得，才符合相关个人所得税免征条件。示例中卖出方税款暂记为 0，十年后的政策不能预先锁定，逐套测算须核实交易时政策和家庭资格。[2026 年起个人销售住房增值税政策](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5246356/content.html)、[个人所得税相关免征规定](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202580/content.html)

其他城市使用时，请替换为当地公积金与交易税费政策。

## 局限与免责

- 本工具是条件测算，不预测未来房价、租金、利率或房屋成交时间，也不判断月供承受能力——家庭现金流与储备请另行核算；
- 贷款重定价、提前还款、税费变动等情景，应从变更月按实际计划重算；
- 计算结果不构成投资、法律或税务建议。
